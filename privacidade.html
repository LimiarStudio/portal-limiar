Política de Privacidade

Última atualização: setembro de 2026

O Portal Limiar é uma ferramenta de uso interno do Studio Limiar, disponibilizada a clientes e colaboradores convidados individualmente para acompanhamento de projetos de obra.

Quais dados coletamos

Nome e e-mail, usados para login (autenticação via Firebase Authentication).

Dados dos projetos cadastrados pela equipe do Studio Limiar: cronograma, relatórios semanais de obra, fotos anexadas aos relatórios, lançamentos financeiros e orçamentos.

Como os dados são armazenados

Os dados ficam armazenados em serviços do Google Cloud (Firebase/Firestore) e no Google Drive do Studio Limiar. Fotos e PDFs de relatórios são salvos no Drive; os demais dados, no Firestore.

Quem tem acesso

O acesso a cada projeto é restrito aos usuários convidados individualmente pelo administrador do sistema (Studio Limiar). Um cliente só visualiza os projetos em que foi cadastrado — nunca os de outros clientes.

Compartilhamento com terceiros

Não vendemos, alugamos ou compartilhamos esses dados com terceiros. Os dados não são usados para publicidade nem analisados para fins comerciais externos ao próprio acompanhamento da obra.
