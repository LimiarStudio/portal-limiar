Termos de Serviço

Última atualização: setembro de 2026

O uso do Portal Limiar é restrito a clientes e colaboradores convidados individualmente pelo Studio Limiar. Não é um serviço de acesso público — o cadastro é feito exclusivamente pelo administrador do sistema.

Uso permitido

O sistema deve ser usado apenas para acompanhamento dos projetos de obra aos quais o usuário tem acesso autorizado. É proibido tentar acessar dados de projetos ou usuários sem autorização.

Conteúdo

O conteúdo disponibilizado (relatórios, fotos, dados financeiros) é fornecido pela equipe do Studio Limiar "como está", para fins informativos de acompanhamento de obra, sem garantias de disponibilidade contínua.

Encerramento de acesso

O Studio Limiar pode revogar o acesso de qualquer usuário a qualquer momento, especialmente ao fim de um projeto ou contrato.

Contato
